# Eco Wood Industries

A modern, sustainable wood recycling platform built with React and Node.js.

## 🌱 About

Eco Wood Industries transforms industrial wood waste into sustainable resources, connecting sellers with buyers for a greener future.

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ 
- npm 9+

### Installation

```bash
# Clone repository
git clone https://github.com/PranavYehale/eco-wood-industry.git
cd eco-wood-industry

# Install client dependencies
cd client
npm install

# Start development server
npm run dev
```

### Production Build

```bash
cd client
npm run build
```

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Routing**: React Router DOM
